# Hold Planner

Offline cargo stowage planner for 10-hold open-hatch bulk carriers. Single-file PWA by Tango Juliet Dev.

- Side profile, Hold 1 fwd to Hold 10 aft, with stacked tiers
- Load and discharge ports with dedicated colours
- Drag and drop parcels between holds and between tiers, split, merge, lock
- Live totals under every hold, LP / DP balance tables, LP × DP matrix
- Overstow, load sequence, hold capacity and bale volume checks
- Undo / redo, autosave on device, JSON backup, CSV export, paste cargo from Excel

Live: https://tangojulietdev.github.io/cargoplan/

Planning tool only. Final figures are always checked on the approved loading computer.
